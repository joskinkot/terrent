# terrent

Торрент-клиент для терминала на [WebTorrent](https://webtorrent.io/docs).
Один процесс — один торрент: скачивает, раздаёт и отдаёт файлы по локальному
HTTP для стриминга в любом плеере.

## Установка и запуск

```bash
npm install
node bin/terrent.js "magnet:?xt=urn:btih:…"
```

Либо глобально, чтобы команда была доступна везде:

```bash
npm link          # появится команда terrent
terrent --help
```

Требуется Node.js 22+ (ограничение WebTorrent 3).

## Использование

```
terrent <торрент> [опции]

  <торрент>   magnet-ссылка, путь к .torrent, http(s) URL или info hash

  -d, --dir <path>       папка загрузки (по умолчанию текущая)
  -p, --port <port>      порт локального HTTP-сервера для стриминга
      --only <шаблон>    качать только подходящие файлы, например "*.mp4"
      --exit-when-done   выйти сразу после завершения загрузки
  -q, --quiet            без прогресс-бара, только важные события
  -h, --help             справка
  -v, --version          версия
```

Примеры:

```bash
# скачать в текущую папку и остаться на раздаче
terrent "magnet:?xt=urn:btih:…"

# только видео, выйти по завершении
terrent ./film.torrent --only "*.mkv" --exit-when-done

# фиксированный порт: URL для плеера печатается в выводе
terrent ./film.torrent -p 8080 -d D:\Downloads
mpv "http://127.0.0.1:8080/webtorrent/<infoHash>/film.mkv"
```

## Поведение

- По умолчанию после завершения загрузки процесс остаётся жить и раздаёт
  торрент. `--exit-when-done` — выйти сразу после завершения.
- `Ctrl+C` — корректная остановка (закрываются соединения, файлы остаются).
  Повторный `Ctrl+C` — принудительный выход.
- `--only` фильтрует файлы по glob (`*`, `?`, регистр не важен); путь и имя
  файла проверяются оба. Прогресс считается только по выбранным файлам.
- Уже скачанные данные переиспользуются: повторный запуск с тем же `-d`
  проверяет файлы на диске и докачивает недостающее.
- Локальный HTTP-сервер слушает только `127.0.0.1` и поддерживает
  `Range`-запросы, поэтому в плеере работает перемотка.

## Структура

```
bin/terrent.js   — точка входа, разбор аргументов и справка
src/args.js      — парсер опций
src/format.js    — форматирование размеров/скоростей/ETA, прогресс-бар, glob
src/progress.js  — вывод в TTY (перерисовка строки) и в pipe
src/download.js  — WebTorrent, стриминг-сервер, выбор файлов, завершение
```

## Заметки

- Нативные модули (`node-datachannel`, `bufferutil`, `utp-native`) собираются
  при `npm install`; разрешения прописаны в `allowScripts` в `package.json`,
  иначе npm 12 блокирует install-скрипты.
- В терминале с кодировкой, отличной от UTF-8, кириллица и символы `█░` могут
  отображаться некорректно — используйте Windows Terminal или `chcp 65001`.
